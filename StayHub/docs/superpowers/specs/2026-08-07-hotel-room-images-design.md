# StayHub 호텔·객실 이미지 디자인

## 목표

StayHub의 기존 모던 부티크 UI에 맞는 지역별 호텔 대표 이미지 10장과 객실 유형 이미지 5장을 생성하고, 호텔뿐 아니라 객실에도 이미지 URL을 저장하고 표시할 수 있게 한다.

## 이미지 구성

호텔 이미지는 서울 시티, 부산 오션, 제주 리조트, 강릉 씨뷰, 경주 한옥, 인천 에어포트, 여수 마리나, 속초 비치, 전주 한옥, 대전 시티의 성격을 각각 반영한다. 객실 이미지는 스탠다드, 슈페리어, 디럭스, 패밀리, 스위트 유형으로 구성한다.

모든 이미지는 실제 예약 사이트에 사용할 법한 고급 숙박 사진 스타일로 생성한다. 따뜻한 자연광, 아이보리·브라운 계열 인테리어, 정돈된 공간, 중앙 중심 구도를 사용하며 사람, 로고, 간판 문구, 워터마크는 포함하지 않는다.

## 파일과 경로

- 생성 이미지는 `stayhub-frontend/public/images/hotels`와 `stayhub-frontend/public/images/rooms`에 저장한다.
- 웹에서 사용하는 URL은 각각 `/images/hotels/<name>`과 `/images/rooms/<name>` 형식으로 저장한다.
- 호텔 이미지는 기존 `Hotel.image` 필드를 그대로 사용한다.
- 객실 모델에 선택적 `image` 문자열 필드를 추가하고 기본값은 빈 문자열로 둔다.

## 백엔드 변경

- `Room` 모델에 `image` 필드를 추가한다.
- 객실 생성 서비스에서 `image`를 받아 저장한다.
- 객실 수정 서비스의 허용 필드에 `image`를 포함한다.
- 기존 객실 데이터는 마이그레이션 없이 계속 동작해야 한다.
- 시드 데이터의 호텔과 객실에 로컬 이미지 URL을 연결한다.

## 프론트엔드 변경

- 객실 등록·수정 폼에 이미지 URL 입력 필드를 추가한다.
- 객실 카드에 이미지가 있으면 표시하고, 없으면 기존 스타일과 어울리는 플레이스홀더를 표시한다.
- 호텔 카드와 객실 카드의 이미지 비율은 가로형으로 통일하고 모바일에서도 과도하게 잘리지 않게 `object-fit: cover`를 사용한다.
- 기존 예약 선택, 객실 수정·삭제, 가용성 표시 동작은 유지한다.

## 오류와 호환성

- 이미지 URL이 비어 있어도 호텔 및 객실 UI는 정상 렌더링되어야 한다.
- 이미지 요청 실패가 API 기능을 방해하지 않도록 이미지는 단순 URL 데이터로 취급한다.
- 기존 API 응답 형식은 `image` 필드가 추가되는 것 외에는 변경하지 않는다.

## 검증 기준

- 호텔 이미지 10장과 객실 이미지 5장이 지정 폴더에 존재한다.
- 백엔드 모델 및 서비스 문법 검사가 통과한다.
- 객실 생성과 수정 요청에서 `image`가 저장된다.
- 객실 폼이 기존 이미지 URL을 불러오고 새 URL을 전송한다.
- 객실 카드가 이미지 유무 두 경우를 모두 처리한다.
- 이미지 경로와 시드 데이터의 URL이 일치한다.
- 프론트 빌드 환경이 있으면 Vite 빌드와 ESLint를 실행한다.

## 범위 제외

- 파일 업로드 API와 클라우드 스토리지는 추가하지 않는다.
- 이미지 갤러리, 다중 이미지, 드래그 앤 드롭은 추가하지 않는다.
- 예약·인증·호텔 비즈니스 로직은 변경하지 않는다.
